# HTML Visualizer

A beautiful, single-page app for previewing, saving, and organizing HTML snippets.

## Features

- **Live Preview**: Paste HTML and see instant live rendering
- **Snippet Management**: Save, load, delete, and organize your HTML code
- **Tags & Categories**: Organize snippets with tags and categories
- **Search & Filter**: Quickly find snippets by title, description, or tags
- **Import/Export**: Backup and restore all snippets as JSON
- **Save to Folder**: Save directly to your local folder (File System Access API)
- **Download**: Download any snippet as a standalone HTML file
- **Responsive**: Works on desktop and mobile devices
- **Offline**: Works entirely offline with localStorage

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + S` | Save snippet |
| `Ctrl/Cmd + B` | Toggle sidebar |
| `Ctrl/Cmd + Enter` | Refresh preview |
| `Escape` | Close modal |

## Usage

1. Paste any HTML code in the editor panel
2. See live preview on the right
3. Click "Save" to store the snippet
4. Access saved snippets from the sidebar
5. Use tags and categories to organize

## Tech Stack

- Vanilla JavaScript (no frameworks)
- HTML5 & CSS3
- localStorage for persistence
- File System Access API for local saving
